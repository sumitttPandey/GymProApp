# GymProApp 💪

A professional gym & fitness tracking app built with **React Native + Expo**.

## Features
- 🏋️ Workout logging
- 📊 Progress tracking
- 🥗 Nutrition & calorie calculation
- 🎥 Exercise videos (YouTube guided)
- 🤖 AI trainer for gym-related queries

## Tech Stack
- React Native
- Expo Router
- TypeScript
- Tailwind / NativeWind
